# Live Cricket Scoring Web Application

A fully responsive, real-time web application designed to digitize local grassroots cricket matches. This platform allows a designated scorer to seamlessly update match events while providing a live, accessible scoreboard for anyone with the match link.

## 🚀 Features
*   **Live Match Scoring:** Real-time updates for runs, wickets, overs, and extras.
*   **Instant Sync:** Viewers can track the game live from anywhere without needing to refresh the page.
*   **Responsive Design:** Optimized for both mobile devices on the pitch and desktop viewing.

## 🛠️ Tech Stack
*   **Frontend:** React, Next.js
*   **Styling:** Tailwind CSS, Shadcn/UI
*   **Backend & Database:** Supabase (PostgreSQL)
*   **Real-Time Infrastructure:** WebSockets (Socket.io)
*   **Deployment:** Vercel
